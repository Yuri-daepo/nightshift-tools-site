LocFlow

A localization workflow studio for Unity's official Localization package. Edit tables, review CSV changes, audit project health, and generate pseudo-locales without sending project data to an external service.

Unity 2022.3+Localization 1.4+Editor extension
01Tables

Edit together

Work across every locale in one spreadsheet-style view, with search, missing-value filters, and safe inline edits.

02CSV

Review every change

Round-trip through CSV with stable IDs and a complete diff. Nothing touches your tables until you approve it.

03Audit

Find issues early

Audit coverage, missing translations, duplicate values, placeholder mismatches, and unlocalized scene text.

04Pseudo

Stress-test the UI

Generate accented, expanded pseudo-locales while preserving placeholders and rich-text tags.

Designed around trust
